==================================================
Airfoil PINN v260226 — физически-информированные нейронные сети
для моделирования обтекания профилей
==================================================

Airfoil PINN — это программный комплекс на языке Python, предназначенный для
решения задач гидро- и аэродинамики с помощью физически-информированных
нейронных сетей (Physics‑Informed Neural Networks, PINNs). Проект позволяет
моделировать стационарное течение вязкой несжимаемой жидкости около профилей
произвольной формы, используя автоматическое дифференцирование для
удовлетворения уравнений Навье‑Стокса и граничных условий.

Ключевая особенность — полная автоматизация процесса: от загрузки геометрии
профиля и построения расчётной области до генерации точек коллокации, задания
свойств жидкости и граничных условий, инициализации полей, обучения нейросети
и визуализации результатов. Все этапы объединены в удобное иерархическое меню,
а настройки сохраняются в конфигурационных файлах.

1. ВОЗМОЖНОСТИ
--------------------------------------------------
- Геометрический модуль (G2D) – загрузка координат профиля, построение
  расчётной области (прямоугольник с вырезом под профиль или полная замкнутая
  область). Все координаты в метрах.
- Генерация точек коллокации (S2DR) – расстановка точек внутри области и на
  границах с классификацией по типам (inlet, outlet, wall, symmetry,
  axis_symmetry). Поддерживаются регулярные, нерегулярные (случайные) и
  адаптивные методы со сгущением к границам.
- Библиотека жидкостей (Fluids) – хранение параметров жидкости/газа
  (плотность, вязкость) в JSON, возможность редактирования.
- Граничные условия (Conditions) – задание давления на входе/выходе, скорости
  на входе (компоненты или модуль+угол), учёт симметрии. Сохранение в JSON.
- Инициализация (Initializer) – создание нормализованного набора данных
  (координаты делятся на хорду, скорости на U_inf, давление на ρU², SDF на
  хорду). Вычисление SDF с поддержкой многопроцессорности.
- Обучение PINN (PINN_Learning) – многоуровневое меню для настройки
  конфигурации, архитектуры сети, функции потерь, стратегии обучения,
  запуска обучения.
- Решатель (solver.py) – реализует полный цикл обучения: двухэтапное обучение,
  детектор локальных минимумов, адаптивную балансировку весов, RAR,
  переключение Adam→L‑BFGS, градиентное накопление, чекпоинты, интерактивное
  управление через горячие клавиши.
- Гибкая архитектура сети – полносвязная сеть с настраиваемыми слоями,
  возможностью добавлять на вход дополнительные параметры (скорость на входе,
  вязкость, плотность, one‑hot границ).
- Поддержка hard граничных условий – жёсткая подстановка значений на границах
  вместо мягкого штрафа.
- Self‑Adaptive веса (SA‑PINN) – обучаемые веса для каждой точки и каждого
  уравнения.
- Интерактивное управление – горячие клавиши для сохранения, редактирования
  весов, сброса оптимизатора, изменения learning rate.
- Визуализация в реальном времени – два окна с графиками PDE и BC,
  обновляющиеся с заданной частотой.
- Сохранение результатов – чекпоинты, графики полей, логи обучения.

--------------------------------------------------
5. ОПИСАНИЕ МОДУЛЕЙ
--------------------------------------------------
5.1. Главный модуль (Airfoil_PINN.py)
--------------------------------------------------
Запускает программу, выводит баннер и главное меню:
1 – Работа с модулями (переход в меню выбора модуля)
2 – Настройки программы (цвет, автосохранение, логирование – заготовка)
3 – Справка
4 – Очистить экран
0 – Выход

Модули со статусом «готов» можно запускать непосредственно из этого меню.

5.2. Геометрия (Geometry.py)
--------------------------------------------------
Класс AirfoilGeometry, функция g2d().
Загружает координаты профиля из файла (метры), определяет замкнутость,
строит расчётную область (прямоугольник с вырезом для незамкнутого профиля
или полный прямоугольник для замкнутого). Сохраняет:
- airfoil_foil.npy – профиль
- airfoil_domain.npy – вершины области
- airfoil_metadata.npy – метаданные (chord, is_closed, число точек)

5.3. Дискретизация (Collocation.py)
--------------------------------------------------
Класс CollocationPoints, функция S2DR().
Генерирует точки коллокации внутри области и на границах с классификацией
типов (inlet, outlet, wall, symmetry, axis_symmetry). Методы генерации:
regular, irregular, adaptive_foil, adaptive_all. Параметры адаптивности:
alpha (степень сгущения), epsilon_factor (масштаб сгущения).
Сохраняет структурированный массив точек, отдельные файлы для внутренних
и граничных точек, метаданные.

5.4. Свойства жидкости (Fluids.py)
--------------------------------------------------
Классы Fluid, FluidLibrary, функция fluids_menu().
Хранит параметры жидкости (плотность, кинематическая вязкость, опционально
динамическая вязкость). Каждая жидкость сохраняется в отдельный JSON.
Меню позволяет просматривать, добавлять, редактировать, удалять, создавать
примеры (воздух, вода, масло, глицерин).

5.5. Граничные условия (Conditions.py)
--------------------------------------------------
Классы BoundaryConditions, ConditionsManager, функция conditions_menu().
Задаёт давление на входе/выходе, скорость на входе (компоненты U,V или
модуль+угол), выбирает жидкость из библиотеки, указывает тип симметрии.
Автоматически обнуляет вертикальную компоненту при симметрии.
Сохраняет в JSON в папке Conditions.

5.6. Инициализация (Initializer.py)
--------------------------------------------------
Класс Initializer, функция initialize_menu().
Загружает точки коллокации, извлекает точки wall для SDF, выбирает жидкость
и условия, вычисляет хорду, нормализует координаты, скорости, давление,
вычисляет SDF (многопроцессорно, с использованием KD‑дерева при наличии scipy).
Поддерживает выбор начальных полей (constant, linear_x, perturbed) и добавление
шума к давлению. Сохраняет структурированный массив с нормализованными полями
(initial.npy) и метаданные.

5.7. Обучение PINN (PINN_Learning.py)
--------------------------------------------------
Главный модуль обучения с иерархическим меню для создания/загрузки/редактирования
конфигурации, настройки всех параметров, запуска обучения через PINNSolver.

5.8. Решатель (solver.py)
--------------------------------------------------
Класс PINNSolver. Содержит:
- Инициализацию устройства, данных, модели, оптимизатора, чекпоинтов.
- Методы вычисления PDE и BC потерь.
- Шаги обучения для Adam и L‑BFGS.
- RAR (Residual‑based Adaptive Refinement).
- Детектор локальных минимумов.
- Интерактивное управление через KeyListener.
- Форматированный вывод таблицы потерь каждую эпоху.

5.9. Модели (models.py)
--------------------------------------------------
- PINNIncompressible – полносвязная сеть с tanh, настраиваемым input_dim,
  скрытыми слоями, output_bias.
- SelfAdaptiveWeights – обучаемые веса для каждой точки и уравнения
  (используются в SA‑PINN).

5.10. Невязки PDE (pde_residuals.py, PDEResiduals.py)
-------------------------------------------------------
Модуль pde_residuals.py содержит функции compute_residuals_2d и
compute_residuals_axisymmetric, которые возвращают словарь с квадратами
невязок для уравнений неразрывности и импульса.

5.11. Обработка данных (data_handler.py)
--------------------------------------------------
Класс DataHandler загружает нормализованные точки и метаданные, создаёт
PINNDataset, который возвращает батч с идентификаторами, координатами, SDF,
one‑hot границ, масками фиксированных компонент и значениями на границах
(для hard ГУ). Хранит физические параметры (хорда, U_inf, Re и др.).

5.12. Конфигурация (config_manager.py)
--------------------------------------------------
Класс ConfigManager управляет загрузкой/сохранением YAML‑файлов конфигурации,
предоставляет методы для глубокого обновления словаря и отображения текущих
настроек. Используется во всех меню настройки.

5.13. Чекпоинты (checkpoint.py)
--------------------------------------------------
Класс CheckpointManager сохраняет и загружает состояние модели, оптимизатора,
истории, SA‑весов, конфигурации и др. Сохраняет в папку, указанную в конфиге.

5.14. Клавиатурный слушатель (key_listener.py)
--------------------------------------------------
Класс KeyListener запускает фоновый поток, отслеживающий горячие клавиши:
Ctrl+P (сохранить графики), Ctrl+W (редактировать веса), Ctrl+R (сброс
оптимизатора), Ctrl+S (сохранить чекпоинт), Ctrl+L (увеличить LR),
Ctrl+K (уменьшить LR), Ctrl+U (установить LR вручную).

5.15. Визуализация (visualizer.py)
--------------------------------------------------
Класс Visualizer создаёт живые графики (два окна: PDE и BC), обновляет их
в процессе обучения, сохраняет финальные поля (scatter u, v, p) с возможностью
выделения граничных точек.

5.16. Утилиты (utils.py)
--------------------------------------------------
- check_memory_usage – проверка доступной памяти.
- safe_grad – безопасное вычисление градиента (возвращает ноль при ошибке).

5.17. Общие импорты (common_imports.py)
--------------------------------------------------
Содержит стандартные импорты для всех модулей (os, sys, time, numpy, torch,
matplotlib и т.д.), чтобы избежать дублирования.

5.18. Пример конфигурации (Test5.yaml)
--------------------------------------------------
Реальный пример настроек для одного из расчётов:
- архитектура: [256, 256]
- входные параметры: координаты, SDF, скорость на входе, вязкость, плотность
- веса PDE: cont=1000, mom_x=1, mom_y=1
- тип ГУ: hard
- SA‑веса: true
- обучение: батч 1200, накопление 20, 2000 эпох, RAR включён
- устройство: cuda, AMP включён

--------------------------------------------------
6. РАБОТА С КОНФИГУРАЦИЕЙ
--------------------------------------------------
Все параметры обучения хранятся в YAML‑файлах в папке Configs/. Основные разделы:
- project_name
- input_params (какие признаки подавать на вход)
- architecture (слои, выходная размерность, смещения)
- pde (система, тип течения)
- boundary_conditions (soft/hard)
- loss_weights (веса PDE, BC, флаги адаптивности, SA, интеграла)
- training (стратегия обучения)
- output (настройки вывода)
- checkpoint (интервал сохранения, шаблоны имён)
- checkpoint_dir
- data (путь к файлу с точками)
- enable_key_listener
- process (устройство, тип данных, AMP, путь к загружаемой модели)

Изменять параметры можно через меню в PINN_Learning.py. Рекомендуется сохранять
конфигурацию после редактирования.

--------------------------------------------------
7. ПОШАГОВЫЙ ПРИМЕР ИСПОЛЬЗОВАНИЯ
--------------------------------------------------
1. Запустите Airfoil_PINN.py.
2. В главном меню выберите 1 → Работа с модулями.
3. Запустите модуль 1 (Geometry). Укажите путь к файлу профиля, задайте
   параметры области. Просмотрите график и сохраните.
4. Запустите модуль 2 (S2DR). Выберите шаг сетки, тип верхней границы,
   метод генерации, при необходимости параметры адаптивности. Дождитесь
   завершения и сохраните.
5. Запустите модуль 3 (Fluids). Создайте новую жидкость (или выберите
   существующую). Выйдите.
6. Запустите модуль 4 (Conditions). Создайте новый набор условий: выберите
   жидкость, задайте давления, режим скорости, угол атаки. Сохраните.
7. Запустите модуль 5 (Initializer). Выберите жидкость и условия, укажите
   режимы инициализации, при необходимости добавьте шум. После вычислений
   постройте графики и сохраните данные.
8. Запустите модуль 6 (PINNLearning). Создайте новую конфигурацию, задайте
   архитектуру, веса, стратегию обучения, вывод, сохранение. Сохраните
   конфигурацию.
9. Выберите пункт 7 (Старт обучения). При необходимости укажите путь к файлу
   с точками (по умолчанию Initial/Data/initial.npy). Наблюдайте за процессом,
   при необходимости используйте горячие клавиши.
10. По окончании обучения результаты будут в папке Checkpoints/.

--------------------------------------------------
8. ФОРМАТЫ ДАННЫХ
--------------------------------------------------
- Геометрия: .npy или .txt (два столбца чисел).
- Точки коллокации: структурированный массив .npy с полями (id, x, y,
  boundary_type, on_airfoil, on_boundary, segment_id).
- Нормализованные данные: структурированный массив .npy с полями (id, x_norm,
  y_norm, sdf_norm, boundary_type, on_boundary, p_norm, u_norm, v_norm).
- Метаданные: словарь, сохранённый через np.save (загружается как .item()).
- Конфигурация: YAML.
- Чекпоинты: словарь PyTorch.

--------------------------------------------------
9. СОВЕТЫ И РЕКОМЕНДАЦИИ
--------------------------------------------------
- Установите scipy для ускорения SDF (KD‑дерево).
- Установите keyboard для интерактивных клавиш (на Linux может потребоваться
  sudo).
- Начинайте с малых конфигураций для отладки.
- Используйте двухэтапное обучение (two_stage: true) для стабилизации.
- При hard ГУ интегральное условие не работает.
- SA‑веса могут улучшить сходимость, но требуют больше ресурсов.
- Регулярно сохраняйте чекпоинты.
- Для больших расчётов используйте AMP и градиентное накопление.

--------------------------------------------------
10. ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ
--------------------------------------------------
- ModuleNotFoundError: No module named 'keyboard' – горячие клавиши
  не работают; установите библиотеку или отключите enable_key_listener.
- Ошибка загрузки геометрии – проверьте формат файла (два столбца чисел).
- Медленное вычисление SDF – установите scipy или уменьшите количество точек.
- CUDA out of memory – уменьшите batch_size, увеличьте gradient_accumulation_steps,
  используйте float16 и AMP.
- Графики не обновляются – если окна закрыты, live‑графики отключаются
  автоматически; сохраняйте через Ctrl+P.
- Не сохраняются логи – проверьте права на запись в папку logs/.
