# Сводка по проверке гипотез: PINN для течения в отводе 90° (Re = 500)

**Дата:** 08.09.2026  
**Задача:** физически корректное восстановление (u, v, p) в 90°-отводе без внешних данных (CFD использован только как эталон для диагностики).  
**Геометрия:** ширина канала W = 0.5 м; радиус осевой линии R = 1.0 м (внутренний 0.75, наружный 1.25); прямой участок 2 м до и после изгиба.  
**Течение:** несжимаемое, ламинарное, Re = U·W/ν = 500 (U = 1 м/с, ν = 10⁻³ м²/с); вход — параболический профиль, выход — давление 10⁵ Па, стенки — no-slip.

## 1. Эталон CFD (Fluent 2020R1)

Файл `docs/export.csv`; координаты Fluent переведены в систему PINN: `x_p = X + 1`, `y_p = Y − 1` (центр дуги → (0,0)); `Cp = (p − 10⁵)/(0.5·ρ·U²)` при ρ = 998 кг/м³, U = 1 м/с.

|---|---|
| Баланс масс | 0.54 % |

| Перепад Cp поперёк канала (r: 0.77→1.23) | **+0.560** |
| Минимум Cp | **−0.492 @ r = 0.76 м (у стенки)** |

**Ключевой факт эталона:** давление минимально **на внутренней стенке** и монотонно растёт к наружной. Это классическая картина разрежения на выпуклой (внутренней) стенке изгиба.

## 4. Выводы о значимости гипотез

**Иерархия влияния на результат (по силе эффекта):**

1. **H1 — нормировка/коэффициент (решающая).** Без исправления FVM-координат и коэффициента `0.5∇Cp` решение нефизично в принципе: дисбаланс масс, «мёртвый» изгиб. Это единственная гипотеза, после которой появилось физичное поле скорости. *Влияние: определяющее.*

2. **H5 — частотный диапазон Fourier (сильная, σ = 12).** Единственный рычаг, который существенно увеличил **амплитуду** давления: размах Cp ×2.1 при сохранении лучшей скорости (баланс 0.09 %). Исправил знак градиента у **наружной** стенки. σ = 48 нестабилен — практический потолок σ ≈ 12 для данной схемы оптимизации. *Влияние: сильное, но не достаточное.*

3. **H3 — сгущение коллокации в изгибе (сильная).** Дал ×2.4 по размаху Cp и ×3.6 по поперечному перепаду на θ=−45° **без ухудшения скорости**. Необходимое условие для давления, но само по себе не создаёт пристеночный пик.

4. **H8 — CFD-эталон (решающая для диагноза).** Показал, что эталон монотонен с минимумом **на внутренней стенке** (Cp = −0.48), а PINN ставит минимум в ядро (Cp_стенки ≈ 0). Это переводит проблему из «плохого давления вообще» в конкретный **дефицит локального разрежения ~0.4 Cp у выпуклой внутренней стенки**.

5. **H6 — wall-pressure (частичная).** Нормальная проекция и полный momentum на стенке дают локальные улучшения (no-slip до 0.016, ∂Cp/∂n корректнее), но **уровень давления вдоль стенки не поднимают**: Cp_стенки остаётся ≈ 0. Причина: дефицит не в граничном условии для p, а в кинематике/представимости пристеночного слоя.

6. **H4 — пристеночное перевзвешивание (отвергнута).** Даёт «0 невязки» momentum у стенки ценой деформации поля скорости и падения баланса масс до 7.5–17.6 %. Якорь скорости (v9) смягчает деформацию, но инверсию не убирает.

7. **H2 — L-BFGS (отвергнута).** Три независимые полировки (v5, v6, v10b) — давление до/после идентично. L-BFGS полирует уже найденный минимум, но не меняет структуру p.

8. **H7 — активации (отвергнута).** ReLU даёт наибольший ΔCp по граням (0.053) и приемлемый профиль, но ломает баланс масс (8.3 %) и формально обнуляет вязкие члены (вторая производная ReLU = 0), что физически недопустимо для NS. tanh/SiLU хуже по BC входа; ни одна активация не создаёт разрежения у внутренней стенки.

**Общий вывод:** архитектурные и гиперпараметрические рычаги **не исчерпаны вообще**, но в рамках текущей постановки они исчерпаны **для данной конкретной дефицитной моды** (пик разрежения у внутренней стенки). Скорость восстанавливается надёжно; давление — только частично (амплитуда и наружная сторона), а пристеночный пик разрежения остаётся вне возможностей ванильной PINN при этих настройках.

## 5. Что это означает для дальнейшей стратегии

- **CFD-регуляризация не является единственным средством**, но на данный момент это самый надёжный способ закрыть дефицит: CFD нужен либо как валидация (что уже сделано), либо как мягкий якорь по давлению в узкой зоне внутренней стенки.
- Общая (геометрия-агностичная) альтернатива: **усилить представимость и разрешение именно в зоне максимальной кривизны потока** (адаптивная коллокация + σ ≈ 12–24 + длинное обучение) и/или **частотная анимация σ** (постепенный рост 3→12→24 в одном прогоне), что снимает проблему нестабильности высокого σ.
- Текущий **лучший компромисс**: `v10b` (σ=12) — по амплитуде Cp (0.348) и скорости (баланс 0.09 %); `v6-polish` — по отсутствию пристеночных искажений скорости.
