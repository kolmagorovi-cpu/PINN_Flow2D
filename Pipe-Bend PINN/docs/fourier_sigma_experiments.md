# Эксперименты v10/v10b: влияние частотного диапазона Fourier (σ) на давление

**Дата:** 04.09.2026
**Контекст:** «двухслойное» давление в отводе (инверсия ∂Cp/∂r у внутренней
стенки) не ушло при сгущении коллокации (v6) и перевзвешивании потерь у стенок
(v7–v9). Гипотеза: низкочастотный базис Fourier (σ=3 → λ≈4 м) не даёт сети
представить пристеночную структуру давления (~0.1–0.2 м).

## Реализация
- `solver.py`: опция `fourier_features.reseed_on_resume` — переинициализация
  случайного базиса B под sigma из конфига после загрузки чекпоинта (иначе
  `load_state_dict` вернул бы B из чекпоинта).

## Прогоны (все — датасет v6, 9315 точек)
- **v10** (`pipe_bend_refine_v10_20260904_122529`): σ=3→12 (reseed), старт
  v6-polish, 2500 эпох — НЕ сошлось (balance 4.1%, ΔCp знак неверный).
- **v10b** (`pipe_bend_refine_v10b_20260904_125648`): продолжение v10 ещё 2500
  эпох (SA/RAR выкл — из-за размера SA после RAR в v10), всего ~5000 эпох.

## Результат v10b (σ=12)

| Метрика | v6-polish (σ=3) | v10b (σ=12) |
|---|---|---|
| Баланс масс | 0.63% | **0.09%** |
| Профиль Пуазейля | 1.98% | **0.92%** |
| no-slip max\|u\| | 0.043 | 0.046 |
| Размах Cp по области | 0.165 | **0.348** |
| ∂Cp/∂r внеш. зона | −0.15 (инверсия) | **+0.14 (верно)** |
| ∂Cp/∂r внутр. зона | −0.11 | −0.63 (инверсия) |
| ΔCp (вход→выход) | −0.007 | +0.018 |

**Вывод:** повышение σ влияет на давление — амплитуда центробежного Cp выросла
в ~2 раза, наружная стенка исправилась. Но инверсия у внутренней стенки
сохранилась/усилилась. Требуется более высокий σ и/или замыкание давления на
стенке.

## Следующий прогон
- **v11** (`pipe_bend_refine_v11_*`): σ=48, обучение С НУЛЯ (10000 эпох,
  two-stage), loss-постановка v6 (mom/pp=2, reference off). Проверка, уходит ли
  инверсия при достаточной представимости высоких частот.

## Результат v11 (остановлен на ~6000/10000 эпох)
σ=48 с фиксированным случайным Fourier-базисом + Adam оказался **численно
нестабильным и медленно сходящимся**:
- профиль Пуазейля на входе на эпохе 5000 — ошибка **25%** (BC входа не
  сошёлся), no-slip max|u| ~0.09, mean|u| по области ~0.09 (поток почти не
  развился);
- cont-невязка периодически «взрывалась» до 1–5 (эпохи ~4500–5900);
- вывод: **практический потолок для данной схемы — σ≈12** (v10b), а σ=48
  требует другой стратегии оптимизации (частотная анимация σ, L-BFGS с самого
  начала, иная инициализация), что выходит за рамки точечного изменения sigma.
