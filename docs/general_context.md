## Обзор проекта

Airfoil PINN — программный комплекс на Python для моделирования обтекания профилей с помощью физически-информированных нейронных сетей (PINNs). Решает уравнения Навье-Стокса для вязкой несжимаемой жидкости.

**Назначение:** Точка входа в приложение, главное меню и навигация по модулям.

**Ключевые компоненты:**

**Функционал:**

### 2. Geometry.py (G2D) — Модуль геометрии

**Назначение:** Загрузка координат профиля и построение расчётной области.

**Ключевые классы:**
- `AirfoilGeometry` — работа с геометрией профиля
- `GeometryConfig` — конфигурация геометрии

**Функционал:**
- Загрузка координат профиля из файлов (.npy, .csv, .txt)
- Определение замкнутости профиля
- Вычисление хорды профиля
- Создание расчётной области:
  - Для незамкнутого профиля — прямоугольник с вырезом

- Сохранение геометрии и метаданных

**Выходные файлы:**
- `airfoil_foil.npy` — координаты профиля
- `airfoil_domain.npy` — вершины расчётной области
- `airfoil_metadata.npy` — метаданные (хорда, замкнутость, число точек)

### 3. Collocation.py (S2DR) — Модуль дискретизации

**Назначение:** Генерация точек коллокации внутри области и на границах.

**Ключевые классы:**
- `CollocationPoints` — генерация и классификация точек
- `SamplerConfig` — конфигурация дискретизации
- `BoundaryType` (Enum) — типы границ (inlet, outlet, wall, symmetry, axis_symmetry, interior)
- `CollocationPoint` (dataclass) — данные точки

**Методы генерации:**
- `regular` — равномерная сетка
- `irregular` — случайное равномерное распределение
- `adaptive_foil` — сгущение к профилю
- `adaptive_all` — сгущение ко всем границам

**Функционал:**
- Генерация точек на внешнем контуре области
- Генерация точек на профиле (WALL)
- Генерация внутренних точек с классификацией
- Многопроцессорные вычисления для ускорения
- Сохранение структурированного массива точек

**Выходные файлы:**
- `collocation_points.npy` — основной файл с точками
- `collocation_points_interior.npy` — внутренние точки
- `collocation_points_boundary.npy` — граничные точки
- `collocation_points_metadata.npy` — метаданные

### 4. Fluids.py — Модуль свойств жидкости

**Назначение:** Управление библиотекой жидкостей/газов.

**Ключевые классы:**
- `Fluid` (dataclass) — параметры жидкости
- `FluidLibrary` — библиотека жидкостей в JSON

**Функционал:**
- Хранение параметров: плотность (ρ), кинематическая вязкость (ν), динамическая вязкость (μ)
- Автоматический расчёт динамической вязкости: μ = ν × ρ
- Сохранение/загрузка из JSON-файлов
- Интерактивное меню для управления библиотекой
- Создание примеров (воздух, вода, масло, глицерин)

**Примеры жидкостей:**
- Воздух (20°C): ρ=1.204 кг/м³, ν=1.516e-5 м²/с
- Вода (20°C): ρ=998 кг/м³, ν=1.004e-6 м²/с

### 5. Conditions.py — Модуль граничных условий

**Назначение:** Задание граничных условий для задачи.

**Ключевые классы:**
- `BoundaryConditions` (dataclass) — параметры граничных условий
- `ConditionsManager` — управление наборами условий

**Функционал:**
- Давление на входе/выходе [Па]
- Скорость на входе в двух режимах:
  - `components` — компоненты (U, V)
  - `magnitude_angle` — модуль + угол атаки
- Выбор жидкости из библиотеки
- Тип симметрии (symmetry, axis_symmetry)
- Автоматическое обнуление вертикальной компоненты при симметрии
- Сохранение в JSON

**Выходные файлы:** `Conditions/*.json`

### 6. Initializer.py — Модуль инициализации

**Назначение:** Нормализация данных и вычисление SDF (Signed Distance Function).

**Ключевые классы:**
- `Initializer` — инициализация расчётной области

**Функционал:**
- Загрузка точек коллокации из Sampler
- Извлечение точек WALL для построения SDF
- Нормализация данных:
  - Координаты: x_norm = x / chord
  - Скорости: u_norm = u / U_inf
  - Давление: p_norm = (p - p_ref) / (ρ × U_inf²)
  - SDF: sdf_norm = sdf / chord
- Вычисление SDF многопроцессорно (с использованием KD-дерева при наличии scipy)
- Выбор начальных полей скорости (constant, linear_x, perturbed)
- Добавление шума к давлению
- Визуализация полей (scatter)

**Выходные файлы:**
- `Initial/Data/initial.npy` — нормализованные данные
- `Initial/Data/initial_metadata.npy` — метаданные (Re, U_inf, chord и др.)
- `Initial/Plots/*.png` — графики полей

### 9. models.py — Модели нейронных сетей

**Назначение:** Определение архитектур нейросетей.

**Ключевые классы:**
- `PINNIncompressible` — полносвязная сеть для предсказания (u, v, p)
- `SelfAdaptiveWeights` — обучаемые веса для SA-PINN
- `Sine` — синусоидальная активация (SIREN)

**PINNIncompressible:**
- Вход: координаты (x, y), SDF, дополнительные параметры (скорость, вязкость, плотность, one-hot границ)
- Скрытые слои: настраиваемая архитектура
- Активации: tanh, relu, sigmoid, leaky_relu, elu, swish, siren
- Выход: (u, v, p) — скорость и давление
- Инициализация: Xavier или специальная для SIREN
- Output bias: начальное смещение выходного слоя

**SelfAdaptiveWeights:**
- Обучаемые веса для каждой точки и уравнения
- Функция активации: Softplus (гарантирует положительность)
- Используется в SA-PINN для автоматической балансировки

### 10. pde_residuals.py — Невязки уравнений

**Назначение:** Вычисление невязок уравнений Навье-Стокса.

**Ключевой класс:**
- `PDEResiduals` — статические методы для вычисления невязок

**Методы:**
- `compute_residuals_2d()` — для 2D плоского течения
- `compute_residuals_axisymmetric()` — для осесимметричного течения

**Уравнения (2D):**
- Неразрывность: ∂u/∂x + ∂v/∂y = 0
- Импульс по x: u·∂u/∂x + v·∂u/∂y + (1/ρ)·∂p/∂x - ν·(∂²u/∂x² + ∂²u/∂y²) = 0
- Импульс по y: u·∂v/∂x + v·∂v/∂y + (1/ρ)·∂p/∂y - ν·(∂²v/∂x² + ∂²v/∂y²) = 0

**Возвращает:** словарь с квадратами невязок {'cont': ..., 'mom_x': ..., 'mom_y': ...}

### 11. data_handler.py — Обработка данных

**Назначение:** Загрузка данных и предоставление DataLoader.

**Ключевые классы:**
- `PINNDataset` (Dataset) — датасет для точек коллокации
- `DataHandler` — загрузчик данных и метаданных

**PINNDataset возвращает:**
- idx — идентификатор точки
- x, y — нормализованные координаты
- sdf — нормализованное SDF
- boundary_types — one-hot编码 типов границ
- mask_u_fixed, mask_v_fixed, mask_p_fixed — маски фиксированных компонент
- u_bc, v_bc, p_bc — значения на границах (для hard constraints)

**Функционал:**
- Загрузка структурированного массива точек
- Обработка one-hot编码 типов границ
- Заполнение масок для hard граничных условий
- Метод `extend()` для добавления точек (RAR)
- Метод `interpolate_profile()` для интерполяции профилей

**Метаданные:**
- chord — хорда профиля
- U_inf — характерная скорость
- p_ref — опорное давление
- rho, mu — плотность и вязкость
- Re — число Рейнольдса

## Компоненты решателя (solver_components/)

### loss_computer.py

**Назначение:** Вычисление функции потерь.

**Класс:** `LossComputer`

**Компоненты:**
- PDE невязки (через `PDEResiduals`)
- Граничные условия (soft/hard)
- Интегральное условие (баланс масс)
- Построение входного тензора
- Применение hard constraints

---

### trainer.py

**Назначение:** Прямой проход и шаги оптимизации.

**Класс:** `Trainer`

**Функционал:**
- `forward_pass()` — прямой проход для батча
- `step_adam()` — шаг оптимизатора Adam
- `step_lbfgs()` — шаг оптимизатора L-BFGS
- `adapt_loss_weights()` — адаптивная балансировка весов BC
- `add_rar_points()` — добавление точек RAR
- Сбор диагностических данных (невязки, градиенты)

---

### metrics.py

**Назначение:** Сбор и логирование метрик.

**Класс:** `MetricsCollector`

**Хранимая история:**
- Общие потери (loss)
- PDE потери по компонентам
- BC потери по типам границ
- Максимальные невязки
- Отношения потерь (rate)
- Нормы градиентов
- Массовый баланс
- Средние скорости на границах

**Функционал:**
- Обновление истории после эпохи
- Форматированный вывод в консоль
- Логирование в файл
- Расчёт физических величин

---

### optimizers.py

**Назначение:** Вспомогательные классы оптимизации.

**Классы:**
- `LocalMinimaDetector` — детектор плато/локальных минимумов
- `CyclicLR` — циклический планировщик learning rate

**LocalMinimaDetector:**
- Скользящее среднее потерь
- Детектирование отсутствия улучшения
- Сигнал для изменения LR

**CyclicLR:**
- Синусоидальное изменение LR
- Параметры: base_lr, max_lr, period

### Форматы файлов

| Тип | Формат | Описание |

| Геометрия | .npy, .txt | Два столбца (x, y) в метрах |

**Точки коллокации:**
```python
dtype = [('id', 'i4'), ('x', 'f8'), ('y', 'f8'), 
         ('boundary_type', 'U20'), ('on_airfoil', 'bool'), 
         ('on_boundary', 'bool'), ('segment_id', 'i4')]
```

```python
dtype = [('id', 'i4'), ('x_norm', 'f8'), ('y_norm', 'f8'), 
         ('sdf_norm', 'f8'), ('boundary_type', 'U20'), 
         ('on_boundary', 'bool'), ('p_norm', 'f8'),
```

## Типичный рабочий процесс

1. **Geometry** → загрузка профиля, создание области
2. **Collocation** → генерация точек коллокации
3. **Fluids** → выбор/создание жидкости
4. **Conditions** → задание граничных условий
5. **Initializer** → нормализация, вычисление SDF
6. **PINNLearning** → настройка конфигурации
7. **Запуск обучения** → solver.py координирует процесс
8. **Результаты** → чекпоинты, графики, логи в Checkpoints/

---

## Стратегии обучения

### Двухэтапное обучение
1. **Этап 1:** Обучение с акцентом на BC (мягкие условия)
2. **Этап 2:** Постепенное увеличение веса PDE

### Переключение на L-BFGS
- После N эпох Adam переключение на L-BFGS для точной сходимости

### RAR (Residual-based Adaptive Refinement)
- Периодическое добавление точек с максимальными невязками
- Улучшение разрешения в критических областях

### SA-PINN (Self-Adaptive)
- Обучаемые веса для каждой точки
- Автоматическая балансировка вклада точек

## Диагностика

**Визуальная:**
- Графики потерь в реальном времени
- Карты невязок
- Профили скорости в сечениях
- 2D спектр (FFT)

**Количественная:**
- Нормы градиентов PDE/BC
- Косинус между градиентами
- Ошибка баланса масс
- Средние скорости на границах
- L2 ошибка относительно эталона

## Рекомендации

1. **Начинайте с малых конфигураций** для отладки
2. **Используйте scipy** для ускорения SDF (KDTree)
3. **Включите two_stage** для стабилизации обучения
4. **Применяйте AMP** и градиентное накопление для больших задач
5. **Регулярно сохраняйте чекпоинты**
6. **Используйте горячие клавиши** для интерактивного управления
