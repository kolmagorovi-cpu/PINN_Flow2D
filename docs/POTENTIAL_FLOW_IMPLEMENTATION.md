# Этап 1.1: Потенциал скорости (уравнение Лапласа)

## Описание

Данная модификация добавляет поддержку решения уравнения Лапласа для потенциала скорости φ(x,y) в программу Airfoil PINN.

### Физическая модель

Для потенцициального потока несжимаемой жидкости:
- **Уравнение**: ∇²φ = 0 (уравнение Лапласа)
- **Скорости**: u = ∂φ/∂x, v = ∂φ/∂y
- **Граничные условия**:
  - **Вход (inlet)**: ∂φ/∂x = U_inf_x, ∂φ/∂y = U_inf_y
  - **Стенка (wall)**: ∂φ/∂n = 0 (условие непротекания)
  - **Выход (outlet)**: ∂φ/∂n = 0 (естественное условие)
  - **Симметрия (symmetry)**: ∂φ/∂n = 0

### Функция потерь

```
loss = λ_laplace * mean((∇²φ)²)
     + λ_inlet * mean((∂φ/∂x - U_inf_x)² + (∂φ/∂y - U_inf_y)²)
     + λ_wall * mean((∂φ/∂n)²)
     + λ_outlet * mean((∂φ/∂n)²)
     + λ_uniform * mean((∂φ/∂x - U_inf_x)² + (∂φ/∂y - U_inf_y)²) [с маской по SDF]
```

### 3. Модель нейросети (`models.py`)

Создан новый класс `PotentialPINN` специально для потенциала скорости:

```python
class PotentialPINN(nn.Module):
    """
    Нейросеть для потенциала скорости φ(x, y).
    Выход: один скаляр (потенциал φ).
    """
    
    def forward(x) -> torch.Tensor:
        """Возвращает потенциал φ."""
        
    def get_velocity(input_tensor, x, y) -> Tuple[torch.Tensor, torch.Tensor]:
        """Вычисляет u = ∂φ/∂x, v = ∂φ/∂y через autograd."""
        
    def get_potential_and_velocity(input_tensor, x, y) -> Tuple[...]:
        """Возвращает (φ, u, v)."""
        
    def get_laplacian(input_tensor, x, y) -> Tuple[...]:
        """Возвращает (φ, u, v, ∇²φ) для вычисления невязки PDE."""
```

**Преимущества отдельного класса:**
- Ясная специализация под один выход
- Встроенные методы для вычисления скоростей и лапласиана
- Оптимизированная архитектура для задачи потенциала

#### Граничные условия для потенциала:

```python
def _compute_potential_bc_loss(phi, boundary_types, x, y, sdf):
    # inlet: (∂φ/∂x - U_inf_x)² + (∂φ/∂y - U_inf_y)²
    
    # wall: (∂φ/∂n)² = 0, где n = ∇SDF / |∇SDF| (точная нормаль из SDF)
    #       Если SDF нет, используется приближение |∇φ|² = 0
    
    # outlet: (∂φ/∂n)² = 0 с вычислением нормали через SDF
    #         Или приближённо ∂φ/∂x = 0
    
    # symmetry: (∂φ/∂y)² = 0 + дополнительно du/dy = 0
    
    # + регуляризация вдали от стенки (с маской по SDF)
```

**Улучшения:**
- ✅ Точное вычисление нормалей через градиент SDF: `n = ∇SDF / |∇SDF|`
- ✅ Корректное условие непротекания: `∂φ/∂n = ∇φ · n = 0`
- ✅ Работает и без SDF (приближённый вариант)

### 7. Архитектура и дизайн

#### Потенциал скорости через отдельный класс

Вместо модификации существующего класса `PINNIncompressible`, создан отдельный класс `PotentialPINN`, что обеспечивает:

1. **Чёткое разделение ответственности**: каждый класс специализирован под свою задачу
2. **Встроенные методы**: `get_velocity()`, `get_laplacian()` для удобной работы с потенциалом
3. **Оптимизация**: архитектура настроена специально для одного выхода
4. **Расширяемость**: легче добавлять новые методы для специфичных операций с потенциалом

#### Вычисление градиентов

Для обучения (с autograd):
```python
# В forward_pass trainer.py
phi = model(input_tensor)
u = safe_grad(phi, x)  # ∂φ/∂x
v = safe_grad(phi, y)  # ∂φ/∂y
```

Для inference (без autograd, через конечные разности):
```python
# В _get_predictions_norm solver.py
eps = 1e-6
u = (model(x+eps) - model(x-eps)) / (2*eps)
v = (model(y+eps) - model(y-eps)) / (2*eps)
```

## Валидация

### Аналитическое решение

Для проверки можно использовать аналитическое решение для обтекания цилиндра:

```
φ(r, θ) = U_inf * (r + R²/r) * cos(θ)
```

### Ожидаемые результаты

После обучения:
1. **Уравнение Лапласа**: mean(|∇²φ|) < 1e-3
2. **Граничные условия**:
   - На входе: |u - U_inf| < 1e-2
   - На стенке: |∂φ/∂n| < 1e-2
3. **Линии тока**: должны быть плавными и симметричными (при α=0)

## Ограничения и будущие улучшения

### Текущие ограничения:
1. Только 2D плоские течения
2. Мягкие граничные условия (hard BC в разработке)
3. Регуляризация работает только для простых геометрий

### Планируемые улучшения (Этап 1.2+):
1. Жёсткие граничные условия для потенциала
2. Автоматический подбор весов функции потерь
3. Многомасштабное обучение (multi-scale training)
4. Переход к Этапу 2: добавление вязкости (уравнения Эйлера → Навье-Стокс)

## Известные проблемы

1. **Медленная сходимость при больших углах атаки**: 
   - Решение: увеличьте `laplace_weight` и используйте SIREN активацию

2. **Артефакты near стенке**:
   - Решение: уменьшите `boundary_layer_thickness` для более точного разрешения пограничного слоя

3. **Проблемы с масштабированием координат**:
   - Решение: убедитесь, что `coordinate_scaling.enabled = true` и `scale_factor` корректно вычислен
