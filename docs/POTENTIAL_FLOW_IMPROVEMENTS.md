### 1. Улучшение `pde_residuals.py`

**Изменения:**
- ✅ Переход на `torch.autograd.grad` напрямую вместо `grad_fn`
- ✅ Добавлены параметры `create_graph=True` и `retain_graph=True` для корректного вычисления высших производных
- ✅ Возвращаются дополнительные ключи для диагностики: `phi_xx`, `phi_yy`
- ✅ Оптимизирован порядок вычисления градиентов для минимизации потребления памяти

**Код:**
```python
def compute_residuals_potential(phi, x, y, grad_fn=None):
    # Первые производные (скорости)
    phi_x = torch.autograd.grad(phi, x, create_graph=True, retain_graph=True)[0]
    phi_y = torch.autograd.grad(phi, y, create_graph=True, retain_graph=True)[0]
    
    # Вторые производные для Лапласиана
    phi_xx = torch.autograd.grad(phi_x, x, create_graph=True, retain_graph=True)[0]
    phi_yy = torch.autograd.grad(phi_y, y, create_graph=False, retain_graph=False)[0]
    
    return {
        'laplace': (phi_xx + phi_yy)**2,
        'u': phi_x,
        'v': phi_y,
        'phi_xx': phi_xx,
        'phi_yy': phi_yy
    }
```

### 2. Улучшение `loss_computer.py`

#### 2.1 Точное вычисление нормалей через SDF

**Раньше:**
```python
# Приближённо: |∇φ|² = u² + v² = 0 на стенке
bc_comp['wall_phi'] = torch.mean(u_w ** 2) + torch.mean(v_w ** 2)
```

**Теперь:**
```python
# Точная нормаль из SDF: n = ∇SDF / |∇SDF|
sdf_x = safe_grad(sdf, x)
sdf_y = safe_grad(sdf, y)
grad_norm = torch.sqrt(sdf_x**2 + sdf_y**2) + 1e-8
n_x = sdf_x / grad_norm
n_y = sdf_y / grad_norm

# Условие непротекания: ∂φ/∂n = ∇φ · n = 0
dphi_dn = u_w * n_x + v_w * n_y
bc_comp['wall_phi'] = torch.mean(dphi_dn ** 2)
```

**Преимущества:**
- ✅ Корректное условие непротекания для произвольной геометрии
- ✅ Работает с любыми формами (не только прямоугольники)
- ✅ Fallback на приближение, если SDF недоступен

#### 2.2 Улучшение outlet conditions

**Раньше:**
```python
# Приближённо: ∂φ/∂x = 0
bc_comp['outlet_phi'] = torch.mean(u_out ** 2)
```

**Теперь:**
```python
# С вычислением нормали через SDF
if sdf is not None:
    sdf_x = safe_grad(sdf, x)
    sdf_y = safe_grad(sdf, y)
    grad_norm = torch.sqrt(sdf_x[mask]**2 + sdf_y[mask]**2) + 1e-8
    n_x = sdf_x[mask] / grad_norm
    n_y = sdf_y[mask] / grad_norm

    bc_comp['outlet_phi'] = torch.mean(dphi_dn ** 2)
else:

    bc_comp['outlet_phi'] = torch.mean(u_out ** 2)
```

### 4. Математическое обоснование

#### Условие непротекания на стенке

Для потенциального потока:
```
v · n = 0  =>  ∇φ · n = 0  =>  ∂φ/∂n = 0
```

где нормаль вычисляется как:
```
n = ∇SDF / |∇SDF|
```

Это более корректно, чем приближение `|∇φ|² = 0`, потому что:
1. Не ограничивает тангенциальную компоненту скорости
2. Работает для произвольных геометрий
3. Сохраняет физический смысл условия непротекания

#### Регуляризация с маской по SDF

```
L_uniform = mean_{x: SDF(x) > δ} [(∂φ/∂x - U_inf_x)² + (∂φ/∂y - U_inf_y)²]
```

где `δ = boundary_layer_thickness` - толщина пограничного слоя.

Это обеспечивает стремление к однородному потоку вдали от стенки, не мешая решению в пограничном слое.

### 5. Тестирование

Для проверки корректности реализации рекомендуется:

1. **Тест на простом случае:** Плоский поток без профиля (должно быть φ = U_inf * x)
2. **Тест на симметрии:** Поток без угла атаки (α = 0) - решение должно быть симметричным
3. **Тест на сходимости:** Проверка, что ∇²φ → 0 во всей области
4. **Тест на BC:** Проверка, что ∂φ/∂n → 0 на стенке

### 7. Известные ограничения

1. **SDF должен быть гладким** - для корректного вычисления градиентов
2. **Требуется requires_grad=True для SDF** - может конфликтовать с некоторыми загрузчиками данных
3. **Численная нестабильность near углах** - может потребоваться сглаживание SDF
