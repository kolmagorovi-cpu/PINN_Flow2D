# РЕФЕРАТ

**Название программы:** «PINN_Flow2D — программный комплекс для двумерного моделирования течений вязкой несжимаемой жидкости на основе физически-информированных нейронных сетей (PINNs)»

**Назначение:** Программный комплекс предназначен для численного моделирования стационарных плоских и осесимметричных течений вязкой несжимаемой жидкости путём решения уравнений Навье-Стокса с использованием физически-информированных нейронных сетей (Physics-Informed Neural Networks, PINNs). Комплекс решает два класса задач гидродинамики:

1. **Внешние течения** (пакет Airfoil PINN, версия 3.260226):
   - обтекание аэродинамических профилей (крыло, лопатка) в открытой расчётной области;
   - течения в плоских тройниках (T-образные и Y-образные соединения каналов) — моделирование потокораспределения в соединительных элементах трубопроводных систем.

2. **Внутренние течения** (пакет Pipe-Bend PINN, версия 1.1):
   - течения в каналах с изгибами (отвод 90° и отводы с произвольным углом поворота) — моделирование течения в U-образных замкнутых каналах с параболическим профилем скорости на входе (профиль Пуазейля).

**Функциональные возможности:**
- Параметрическая генерация расчётной области (профили — из файлов координат; тройники — YAML-конфигурация; отводы — YAML-конфигурация с параметрами: длина входного/выходного участка, радиус изгиба, ширина канала, угол изгиба);
- Генерация точек коллокации четырьмя методами: равномерная сетка, случайное распределение, адаптивное сгущение к телу (профиль/стенки), адаптивное сгущение ко всем границам;
- Автоматическая классификация граничных точек (INLET, OUTLET, WALL, SYMMETRY) на основе геометрии контура;
- Вычисление знаковой функции расстояния (Signed Distance Function, SDF) до границ области с использованием KD-дерева (многопроцессорная обработка);
- Библиотека физических свойств жидкостей и газов (плотность, кинематическая и динамическая вязкость) в формате JSON;
- Задание граничных условий: давление на входе/выходе; равномерный или параболический профиль скорости;
- Архитектура нейронной сети: полносвязная сеть прямого распространения с поддержкой различных функций активации (Tanh, SIREN/sine);
- Двухэтапное обучение (Two-Stage Training): этап акцента на граничные условия → этап постепенного увеличения веса невязок PDE с автоматическим переключением оптимизатора Adam → L-BFGS;
- RAR (Residual-based Adaptive Refinement) — адаптивное добавление точек коллокации в областях с максимальными невязками;
- SA-PINN (Self-Adaptive Weights) — обучаемые веса для каждой точки, автоматическая балансировка вклада граничных условий;
- AMP (Automatic Mixed Precision) и градиентное накопление для эффективного использования памяти GPU при больших задачах;
- Детектор локальных минимумов (плато) с автоматическим сбросом оптимизатора и увеличением learning rate;
- Циклический learning rate scheduler;
- Интерактивное управление обучением через горячие клавиши (сохранение чекпоинтов, изменение learning rate, сброс оптимизатора, редактирование весов функции потерь, сохранение графиков);
- Система чекпоинтов с сохранением/восстановлением полного состояния обучения (веса модели, оптимизатора, планировщика, адаптивных весов, истории метрик, состояния датасета);
- Визуализация в реальном времени: графики невязок PDE и граничных условий, карты невязок, профили скорости в сечениях, двумерный FFT-спектр;
- Количественная диагностика: нормы градиентов PDE/BC, ошибка баланса масс, средние скорости на границах, L2-ошибка относительно эталонного решения (CFD);
- Режим пакетных экспериментов: автоматический перебор сетки гиперпараметров, запуск в subprocess, сбор сводных метрик в CSV;
- Постобработка результатов: построение графиков истории обучения, визуализация предсказанных полей скорости и давления, сохранение полей в формате NumPy (.npy) для дальнейшего анализа.

**Область применения:** Научные исследования в области вычислительной гидродинамики (CFD), аэродинамики, проектирования трубопроводных систем, а также образовательный процесс при изучении методов машинного обучения в задачах механики сплошных сред.

**Язык программирования:** Python 3

**Тип реализующей ЭВМ:** Персональный компьютер (IBM PC-совместимый) с графическим процессором NVIDIA (CUDA-совместимый) или CPU-only режим.

**Операционная система:** Windows 10/11, Linux

**Объём программы:**
- **Airfoil PINN:** ~25 модулей исходного кода (Python), включая модули геометрии (профили, тройники), дискретизации, решателя с компонентами (loss_computer, trainer, metrics, optimizers, interactive), управления конфигурацией, визуализации, чекпоинтов, пакетных экспериментов, а также веб-интерфейс на Flask;
- **Pipe-Bend PINN:** ~20 модулей исходного кода (Python), включая модули геометрии отводов, дискретизации, решателя с компонентами, управления конфигурацией, визуализации, чекпоинтов, тестирования;
- **Вспомогательные файлы:** YAML-конфигурации, JSON-библиотеки жидкостей и граничных условий, документация, скрипты запуска.

**Используемые библиотеки:** PyTorch (≥2.0), NumPy (≥1.24), Matplotlib (≥3.7), SciPy (≥1.10), Shapely (≥2.0), PyYAML (≥6.0), keyboard (≥0.13.5), tqdm (≥4.65), psutil (≥5.9).

**Новизна:**
- Единый программный комплекс, объединяющий моделирование внешних (обтекание профилей) и внутренних (каналы с изгибами) течений на основе PINN-подхода;
- Поддержка трёх типов геометрий (профиль, тройник, отвод) с параметрической генерацией расчётной области;
- Сочетание методов стабилизации обучения (Two-Stage Training, SA-PINN, RAR, AMP) в рамках единого решателя;
- Система чекпоинтов с полным сохранением состояния датасета для продолжения обучения после добавления точек RAR.
