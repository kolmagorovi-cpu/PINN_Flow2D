# Эксперимент v6: сгущение коллокации в изгибе (путь №2)

**Дата:** 03.09.2026
**Цель:** проверить гипотезу, что «плоское» давление (ΔCp≈0 при корректной
скорости в v5) вызвано недостаточным разрешением коллокации в области изгиба,
и получить **общий** (геометрия-агностичный) воркфлоу сгущения, применимый к
другим исходным данным и геометриям.

## Гипотеза и диагностика перед экспериментом

На v5/polish поле давления имело правильную локальную структуру
(|∇²p| rms ≈ 0.22 в изгибе, PP-источник |−2∇·(u·∇u)| ≈ 0.26, PP-невязка ≈ 0.095),
но малую амплитуду (размах Cp ≈ 0.068) и «рваность». Momentum в изгибе был
недожат (остаток до 0.35), т.е. точек коллокации/потерь в изгибе не хватало,
чтобы модель развила ∇p.

## Реализованный механизм (общий воркфлоу)

`pipe_bend_pinn/sampling/core.py`:

- `_refine_interior_near_curved_walls()` — геометрия-агностичное пристеночное
  сгущение: контур передискретизируется, вычисляется локальная кривизна κ;
  «криволинейный» участок = κ·pipe_width ∈ [lo, hi] (прямые стенки κ≈0 и
  острые углы κ·W >> hi исключаются с окрестностью); из узлов участка по
  внутренней нормали добавляются interior-точки на расстояниях
  `offsets_frac·step_size`. Плотность вдоль стенки = `station_frac·step_size`,
  поэтому изгиб сгущается автоматически без ручного выделения подобластей.
  Для прямой трубы/другой геометрии механизм остаётся валидным (нужны только
  контур + pipe_width).
- `generate_collocation(..., wall_refine=True, wall_refine_curvature_lo=0.25,
  wall_refine_curvature_hi=6.0, wall_refine_station_frac=0.25,
  wall_refine_offsets_frac=(0.5,1,1.5,2.25,3.25,4.5,6.0,7.5))`.

Новая коллокация: **9315 точек** (interior 8295 = базовые 6849 + 1446 в изгибе;
boundary 1020). 98 % дополнительных точек попало в квадрант изгиба (x>0, y<0).
Поля пересчитаны `Initializer` (режим `stream_function`, как в v5).

## Результаты

Единая база измерений (профиль Cp по радиальной линии в середине изгиба,
θ=−45°, норм. r 1.55…2.45, внешняя − внутренняя стенка; размах Cp по всем
точкам коллокации):

| модель | dCp(внеш−внутр) @θ=−45° | размах Cp по области | размах Cp на радиусе @45° |
|---|---|---|---|
| v5-final | +0.012 | 0.068 | 0.040 |
| polish (135834) | +0.012 | 0.068 | 0.040 |
| **v6-refine-final** | **+0.044** | **0.165** | **0.147** |

Интегральные метрики v6-final: баланс масс 0.76 %, профиль Пуазейля на входе
2.0 %, no-slip max|u| = 0.043 м/с, fvm_rms = 0.065.

Профили Cp на θ = −75/−45/−15° монотонны (внешняя стенка выше, экстремумы в
ядре канала t≈0.26…0.76, размах 0.13–0.15) — центробежная структура развилась,
«рваность» ушла.

## Вывод

Сгущение коллокации в области кривизны — рабочий рычаг для давления:
центробежный перепад Cp вырос в ~3.6 раза, полный размах Cp — в ~2.4 раза
при сохранённой физически корректной скорости. Амплитуда ещё ниже физической
(~0.2–0.4 ΔCp ожидаемо для изгиба R/W=2, Re=500), что оставляет пространство
для продолжения (L-BFGS-полировка на сгущённой коллокации / больше эпох /
ещё выше PP-mom).
