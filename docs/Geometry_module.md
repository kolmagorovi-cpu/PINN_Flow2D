# Geometry.py — Модуль геометрии профилей (G2D)

**Версия:** 3.260226  
**Автор:** Колмагоров И.Д.  
**Назначение:** Загрузка координат аэродинамических профилей и построение расчётной области

---

## Описание

Модуль `Geometry.py` предоставляет функционал для работы с геометрией аэродинамических профилей (крыло). Все координаты хранятся и обрабатываются в метрах без нормализации.

Модуль поддерживает загрузку профилей из различных форматов, автоматическое определение замкнутости профиля, вычисление хорды, создание расчётной области и визуализацию геометрии.

## Классы

### GeometryConfig

Класс конфигурации для геометрических параметров.

#### Атрибуты

| Атрибут | Тип | Значение по умолчанию | Описание |
|---------|-----|----------------------|----------|
| `save_format` | `str` | `'npy'` | Формат сохранения файлов (`'npy'`, `'csv'`, `'txt'`) |
| `plot_enabled` | `bool` | `True` | Включена ли визуализация |
| `plot_show` | `bool` | `True` | Показывать ли график сразу после построения |
| `plot_dpi` | `int` | `300` | DPI для сохранения графиков |
| `output_dir` | `str` | `"Geometry/Data"` | Директория для выходных файлов |

#### Методы

##### `to_dict() → GeometryConfigDict`

Преобразует конфигурацию в типизированный словарь.

**Возвращает:**
- `GeometryConfigDict` — словарь с параметрами конфигурации

### AirfoilGeometry

Основной класс для работы с геометрией профиля и расчётной области.

#### Атрибуты

| Атрибут | Тип | Описание |
|---------|-----|----------|
| `foil_coords` | `np.ndarray` | Координаты точек профиля формы `(N, 2)` |
| `domain_coords` | `np.ndarray` | Координаты точек расчётной области |
| `is_closed` | `bool` | Флаг замкнутости профиля |
| `config` | `GeometryConfig` | Конфигурация геометрии |
| `chord` | `float` | Хорда профиля [м] |

#### Методы

##### `__init__(config: Optional[GeometryConfig] = None) → None`

Инициализирует геометрию профиля.

**Параметры:**
- `config` — конфигурация геометрии (по умолчанию создаётся новая `GeometryConfig()`)

**Пример:**
```python
config = GeometryConfig(save_format='npy', plot_show=True)
geom = AirfoilGeometry(config)
```

##### `load_airfoil(filepath: str) → bool`

Загружает профиль из файла с координатами.

**Параметры:**
- `filepath` — путь к файлу с координатами (`.npy`, `.csv`, `.txt`, `.dat`)

**Возвращает:**
- `True` если загрузка успешна, иначе `False`

**Поддерживаемые форматы:**
- `.npy` — бинарный формат NumPy
- `.csv` — CSV с разделителем запятая
- `.txt`, `.dat` — текстовый файл с координатами, разделёнными пробельными символами

**Пример:**
```python
success = geom.load_airfoil('naca0012.dat')
if success:
    print(f"Хорда профиля: {geom.chord:.4f} м")
```

**Логирование:**
- `INFO` — количество загруженных точек, хорда, замкнутость
- `ERROR` — ошибки загрузки, неверное количество столбцов

---

##### `_load_text_file(filepath: str) → np.ndarray`

Внутренний метод загрузки из текстового файла.

**Параметры:**
- `filepath` — путь к текстовому файлу

**Возвращает:**
- Массив координат формы `(N, 2)`

**Особенности:**
- Пропускает пустые строки и комментарии (начинающиеся с `#`)
- Разбивает строки по любым пробельным символам
- Преобразует координаты в `float`

---

##### `_check_closed(tolerance: float = 1e-6) → bool`

Проверяет замкнутость профиля.

**Параметры:**
- `tolerance` — допуск для сравнения первой и последней точек [м]

**Возвращает:**
- `True` если профиль замкнут (первая и последняя точки совпадают), иначе `False`

---

##### `create_domain(**kwargs: Union[float, int]) → Optional[np.ndarray]`

Создаёт расчётную область вокруг профиля.

**Параметры:**
- `front` — длина домена перед профилем [м] (для незамкнутого)
- `rear` — длина домена за профилем [м] (для замкнутого)
- `top` — высота домена над профилем [м]
- `bottom` — высота домена под профилем [м] (для замкнутого)

Если параметры не указаны, запрашиваются интерактивно через `input()`.

**Возвращает:**
- Массив координат области формы `(N, 2)` или `None` если профиль не загружен

**Особенности:**
- Для **незамкнутого профиля** (крыло) создаётся замкнутый контур, включающий профиль и внешние границы
- Для **замкнутого профиля** создаётся прямоугольная область

**Пример:**
```python
domain = geom.create_domain(front=0.5, top=0.3)
```

---

##### `_create_unclosed_domain(params: DomainParamsDict) → np.ndarray`

Создаёт область для незамкнутого профиля (крыло).

**Параметры:**
- `params` — словарь с параметрами `front`, `top`

**Возвращает:**
- Массив координат замкнутого контура

**Алгоритм построения:**
1. Добавляет ВЕСЬ профиль в исходном порядке точек
2. От хвостика вверх до верхней границы
3. Влево до левой границы
4. Вниз до нижней границы (уровень носка)
5. Вправо до носка профиля (замыкание контура)

---

##### `_create_closed_domain(params: ClosedDomainParamsDict) → np.ndarray`

Создаёт замкнутую прямоугольную область для замкнутого профиля (профиль в трубе).

**Параметры:**
- `params` — словарь с параметрами `front`, `rear`, `top`, `bottom`

**Возвращает:**
- Массив координат прямоугольника формы `(5, 2)` (последняя точка совпадает с первой)

---

##### `_get_y_at_x(x_target: float) → float`

Находит координату Y на профиле при заданном X методом линейной интерполяции.

**Параметры:**
- `x_target` — целевая X-координата [м]

**Возвращает:**
- Y-координата на профиле [м]

**Особенности:**
- Сортирует точки по X для корректной интерполяции
- Удаляет дубликаты X
- Использует `scipy.interpolate.interp1d` с экстраполяцией

---

##### `plot(title: str = "Геометрия задачи", save_path: Optional[str] = None) → None`

Визуализирует геометрию (профиль и расчётную область).

**Параметры:**
- `title` — заголовок графика
- `save_path` — путь для сохранения изображения (опционально)

**Отображение:**
- **Профиль:** синяя линия (`'b-'`), точки — синие кружки
- **Область:** красная линия (`'ro-'`), вершины — красные квадраты
- **Аннотации:** «Носок» и «Хвостик» профиля

**Пример:**
```python
geom.plot(title="Профиль NACA 0012", save_path="geometry.png")
```

---

##### `save(filename: Optional[str] = None, format: Optional[str] = None) → Tuple[Optional[str], Optional[str]]`

Сохраняет геометрию в файлы.

**Параметры:**
- `filename` — базовое имя файла (по умолчанию `"airfoil"`)
- `format` — формат сохранения (по умолчанию из конфига)

**Возвращает:**
- Кортеж `(foil_path, domain_path)` — пути к сохранённым файлам

**Сохраняемые файлы:**
- `{filename}_foil.{fmt}` — координаты профиля
- `{filename}_domain.{fmt}` — координаты области
- `{filename}_metadata.npy` — метаданные (хорда, замкнутость, количество точек)

**Пример:**
```python
foil_path, domain_path = geom.save('naca0012', format='npy')
```

---

##### `_save_coords(coords: np.ndarray, basename: str, fmt: str) → str`

Внутренний метод сохранения координат.

**Параметры:**
- `coords` — массив координат формы `(N, 2)`

- `fmt` — формат (`'npy'`, `'csv'`, `'txt'`)

**Возвращает:**
- Полный путь к сохранённому файлу

## Главная функция

### `g2d() → None`

Запускает интерактивный сеанс модуля геометрии.

**Последовательность действий:**
1. Очистка экрана, вывод заголовка
2. Создание конфигурации
3. Запрос пути к файлу профиля
4. Загрузка профиля
5. Вывод статистики
6. Создание расчётной области
7. Визуализация
8. Сохранение результатов

**Запуск:**
```bash
python Geometry.py
```

## Форматы входных файлов

### Текстовый формат (.txt, .dat)

```
# Координаты профиля NACA 0012
# x (м)    y (м)
0.0000    0.0000
0.0125    0.0087
0.0250    0.0125
...
1.0000    0.0000
```

### CSV формат (.csv)

```csv
x,y
0.0000,0.0000
0.0125,0.0087
0.0250,0.0125
```

### NumPy формат (.npy)

Бинарный массив NumPy формы `(N, 2)`.

|------|--------|----------|
| `airfoil_foil.npy` | `(N, 2)` | Координаты профиля |
| `airfoil_domain.npy` | `(M, 2)` | Координаты области |
| `airfoil_metadata.npy` | `dict` | Метаданные: `chord`, `is_closed`, `num_foil_points`, `num_domain_points` |

## Примеры использования

### Пример 1: Загрузка и визуализация профиля

```python
from Geometry import AirfoilGeometry, GeometryConfig

config = GeometryConfig(plot_show=True, save_format='npy')
geom = AirfoilGeometry(config)

# Загрузка
geom.load_airfoil('naca0012.dat')

# Создание области
geom.create_domain(front=0.5, top=0.3)

# Визуализация
geom.plot(title="NACA 0012")

# Сохранение
geom.save('naca0012')
```

### Пример 2: Работа с замкнутым профилем

```python
geom = AirfoilGeometry()
geom.load_airfoil('closed_foil.npy')

if geom.is_closed:
    # Для замкнутого профиля нужны 4 параметра
    geom.create_domain(front=0.5, rear=1.0, top=0.3, bottom=0.3)
else:
    # Для незамкнутого — 2 параметра
    geom.create_domain(front=0.5, top=0.3)
```

### Пример 3: Получение статистики

```python
geom.load_airfoil('profile.txt')
geom.print_stats()

print(f"Хорда: {geom.chord:.4f} м")
print(f"Замкнутый: {geom.is_closed}")
```

## Логирование

Модуль использует стандартный логгер Python:

```python
logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(levelname)s - %(message)s')

```

**Уровни логирования:**

---

## Рекомендации

1. **Формат координат:** Все координаты должны быть в метрах
2. **Замкнутость:** Для замкнутых профилей первая и последняя точки должны совпадать
3. **Порядок точек:** Для незамкнутых профилей порядок точек сохраняется (важно для обтекания)
4. **Размеры области:** Выбирайте размеры области так, чтобы границы не влияли на решение
5. **Визуализация:** Всегда проверяйте геометрию визуально перед запуском обучения
