# План переработки пакета "Airfoil PINN" для задачи отвода 90°

**Дата:** 16.07.2026
**Задача:** Адаптация существующего PINN-решателя для моделирования течения в отводе 90° направо (плоское течение в плоскости симметрии)

---

## 1. Анализ существующего пакета

Пакет «Airfoil PINN» предназначен для решения уравнений Навье-Стокса с помощью PINNs для **двух типов геометрий**:

| Тип | Описание | Контур | Вход | Выход | Стенки |
|-----|----------|--------|------|-------|--------|
| **airfoil** | Обтекание профиля | Незамкнутый профиль внутри прямоугольной области | Левая граница | Правая граница | Только профиль |
| **pipe_bend** (NEW) | Отвод 90° | U-образный изогнутый канал | Входной патрубок (слева) | Выходной патрубок (сверху) | Внешняя + внутренняя стенки изгиба |

Течение в отводе 90° рассматривается **в плоскости симметрии** — как 2D задача (плоское течение).

---

## 2. Ключевые отличия pipe_bend от airfoil

| Аспект | Airfoil | Pipe Bend |
|--------|---------|-----------|
| Количество каналов | 1 (прямой) | 2 (вход, выход, соединённые изгибом) |
| Внутреннее тело | Есть (профиль) | Есть (внутренняя стенка изгиба) |
| Симметрия | symmetry/axis_symmetry | Нет (плоское течение) |
| Форма контура | Прямоугольник + профиль | Прямоугольник + две дуги окружности |
| Профиль скорости на входе | Равномерный | Параболический (Пуазейль) |

## 3. Детальный план работ

### 3.1. Часть 1: Геометрия отвода (PipeBendGeometry)

**Новый класс `PipeBendGeometry`** (добавить в `Geometry.py` как второй тип геометрии):

**Параметры отвода:**
```yaml
pipe_bend_params:
  inlet_length: 2.0       # Длина входного прямого участка [м]
  outlet_length: 2.0      # Длина выходного прямого участка [м]
  bend_radius: 1.0        # Радиус изгиба по оси канала [м]
  pipe_width: 0.5         # Ширина канала (диаметр трубы) [м]
  bend_angle: 90          # Угол изгиба [°]
```

**Генерация контура (8 вершин, замкнутый):**

```
Точка 0: левый нижний угол входа
Точка 1: левый верхний угол входа  
Точка 2: начало внешней дуги изгиба
Точка 3: конец внешней дуги изгиба (верх)
Точка 4: правый верхний угол выхода
Точка 5: правый нижний угол выхода (внутренняя стенка)
Точка 6: конец внутренней дуги изгиба
Точка 7: начало внутренней дуги изгиба
Замыкание: точка 7 → точка 0 (внутренняя стенка входного участка)
```

- Внешняя дуга: arc radius = bend_radius + pipe_width/2
- Внутренняя дуга: arc radius = bend_radius - pipe_width/2
- Дуги аппроксимируются набором точек (N ≥ 50 для гладкости)

**Методы:**
- `load_from_yaml(yaml_path, bend_name)` — загрузка из библиотеки
- `load_from_config(config_path)` — загрузка из geom_config.yaml
- `create_domain()` — генерация контура с дугами
- `plot(title, save_path)` — визуализация с аннотациями
- `save(filename, format)` — сохранение .npy/.csv/.txt
- `print_stats()` — вывод параметров

### 3.3. Часть 3: Адаптация дискретизации (Collocation.py)

**Классификация границ для pipe bend:**
- Сегмент 0→1: **INLET** (входной патрубок, x = x_min)
- Сегмент 1→2→3: **WALL** (внешняя стенка: прямой участок + дуга + прямой участок выхода)
- Сегмент 3→4: **OUTLET** (выход, y = y_max)
- Сегмент 4→5→6→7: **WALL** (внутренняя стенка: прямой участок выхода + дуга + прямой участок входа)
- Сегмент 7→0: **WALL** (внутренняя стенка входного участка, x = x_min + pipe_width)

**Метод `_sample_boundary_pipe_bend()`:**
- Использует нормализованное расстояние вдоль контура для определения типа границы
- Для дуг — дополнительная проверка по координатам (x, y) для точной классификации
- Назначает `channel_id`: 'inlet', 'outlet', 'wall_outer', 'wall_inner'

**Генерация внутренних точек:**
- Все 4 метода: regular, irregular, adaptive_foil, adaptive_all
- Для adaptive_foil — сгущение к обеим стенкам изгиба

### 3.4. Часть 4: Адаптация граничных условий (Conditions.py)

- Для pipe bend **не требуется симметрия** (плоское течение)
- Давление: inlet_pressure > outlet_pressure (перепад создаёт течение)
- Скорость на входе: **параболический профиль** (Пуазейль) для ламинарного течения
- Опция: равномерный профиль для турбулентного течения (упрощённо)

**Новый метод `_get_velocity_profile(y, pipe_width, mode)` в BoundaryConditions:**
- `parabolic`: U(y) = U_max * (1 - (2y/D)²)
- `uniform`: U(y) = U_avg

### 3.5. Часть 5: Адаптация инициализации (Initializer.py)

- **SDF** — расстояние до ближайшей стенки (внешней или внутренней)
- Внутренняя стенка изгиба играет роль "внутреннего тела" (как профиль в airfoil)
- **Нормализация:** x/pipe_width, u/U_inf, p/(ρU²), sdf/pipe_width
- **Начальное поле скорости:** параболический профиль на входе, линейное затухание вдоль канала
- **Начальное давление:** линейное от inlet_pressure к outlet_pressure

### 3.6. Часть 6: Адаптация обучения

**Уравнения PDE — без изменений** (2D Навье-Стокс, `pde_residuals.py`)

**Функция потерь — убрать неиспользуемые типы:**
```yaml
loss_weights:
  cont: 1.0
  mom_x: 1.0
  mom_y: 1.0
  inlet: 5000.0
  outlet: 5000.0
  wall: 5000.0
# Убраны: symmetry, axis_symmetry, symmetry_grad, axis_symmetry_grad
```

**Boundary types для loss_computer:**
- `inlet`: маска U_fixed=True, V_fixed=True
- `outlet`: маска P_fixed=True
- `wall`: маска U_fixed=True, V_fixed=True (для обеих стенок)

**Тип течения в конфигурации:**
```yaml
flow_type: planar  # для pipe bend (не symmetry, не axisymmetric)
```

## 5. Архитектура workflow для pipe bend

```
┌────────────────────────────────────────────────────────────────┐
│                    Pipe Bend PINN Workflow                      │
├────────────────────────────────────────────────────────────────┤
│                                                                  │
│  [Geometry] → PipeBendGeometry                                   │
│     ├── Загрузка из pipe_bend_geoms.yaml                        │
│     ├── Генерация контура (8 вершин + дуги)                     │
│     └── Сохранение .npy / .csv                                  │
│       ↓                                                          │
│  [Collocation] → CollocationPoints                               │
│     ├── Классификация границ (INLET/OUTLET/WALL)                │
│     ├── Точки на стенках (внешняя + внутренняя)                 │
│     └── Внутренние точки (4 метода)                             │
│       ↓                                                          │
│  [Fluids] → FluidLibrary                                         │
│     └── Выбор жидкости (вода, воздух)                           │
│       ↓                                                          │
│  [Conditions] → BoundaryConditions                               │
│     ├── Давление на входе/выходе                                │
│     ├── Профиль скорости (параболический/равномерный)           │
│     └── Без симметрии                                           │
│       ↓                                                          │
│  [Initializer] → Initializer                                     │
│     ├── Нормализация (x/pipe_width, u/U_inf)                    │
│     ├── SDF до двух стенок                                      │
│     └── Начальное поле (профиль Пуазейля + линейное давление)   │
│       ↓                                                          │
│  [PINNLearning] → PINNSolver                                     │
│     ├── Конфигурация (без symmetry)                             │
│     ├── Обучение (2D Навье-Стокс)                               │
│     └── Результаты: поля скорости и давления                    │
│                                                                  │
└────────────────────────────────────────────────────────────────┘
```

## 6. Схема контура отвода 90° (Pipe Bend)

```
                        y
                        ↑
             OUTLET     │
         ┌──────────────┤
         │              │   Точка 3 (конец внешней дуги)
         │  WALL_out    │
         │    ┌──────┐  │
         │    │      │  ├── Точка 4 (правый верх выхода)
         │    │      │  │
         │    │      │  │   WALL_out (вертикальный выходной участок)
         │    │      │  │
         │    │      ├──┤── Точка 5 (правый ниж выхода)
         │    │      │  │
         │    │      │  ├── Точка 6 (конец внутренней дуги)
         │    │  дуга│  │
         │    │  90° │  │
         │    │      │  │
─────┐   │    │      │  │
INLET│   │    │      │  │
─────┘   │    │      │  │
         │    └──────┘  │
         │  WALL_in     │
         │              │
Точка 0 ─┼──────────────┘──→ x
Точка 7  Точка 1
(левый   (правый верх входа)
низ      Точка 2 (начало внешней дуги)
входа)
```
