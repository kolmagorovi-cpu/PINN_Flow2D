# SA-PINN: обучение и диагностика

Нейросеть минимизирует взвешенный loss, а положительные SA-веса увеличивают
его через обращение градиента. Обе группы Adam используют
`optimizer_params.lr`; отдельный устаревший `sa_lr` не применяется.
На этапе L-BFGS адаптивные веса заморожены.

При `sa_apply_to_bc=True` вклад каждого активного типа границы равен
`loss_weights[name] * mean(sa_weight * point_residual_squared)`.
Эта же комбинация коэффициентов используется в точечном BC-score для RAR.
Hard BC и BC с нулевым коэффициентом не обучают соответствующие SA-веса.
Дополнительные штрафы производных на границах сохраняют свои коэффициенты.

Для ReduceLROnPlateau, детектора плато, early stopping и выбора лучшей эпохи
используется `convergence_loss`: сумма невзвешенных MSE компонентов PDE
и основных BC. Каждый MSE усредняется по участвующим точкам соответствующего
компонента. В критерий не входят SA-веса, коэффициенты loss и множитель
стадийного обучения. Дополнительные штрафы производных, integral и FVM
в него не входят; в частности, пропуск вычисления FVM по расписанию
не создаёт искусственного улучшения критерия. Полный взвешенный `loss`
по-прежнему используется для обратного распространения и записывается отдельно.
Критерий считается на текущей обучающей выборке; RAR меняет её состав.

При RAR объект Adam и scheduler сохраняются. Для расширенного SA-параметра
переносятся моменты старых строк, включая `max_exp_avg_sq` для AMSGrad;
моменты новых строк равны нулю. Счётчик Adam `step` общий для всего параметра
и сохраняется. Моменты параметров нейросети не меняются при вставке точек.

Через `diagnostics.interval` выводится статистика отдельно для каждого
уравнения и типа BC: число активных точек, среднее, минимум, максимум,
квантили 5/25/50/75/95% и гистограмма из десяти интервалов с границами.
Используются эффективные положительные SA-веса, а не их внутренние параметры.
PDE-статистика учитывает маску допустимости SDF, BC-статистика — только точки
соответствующей активной границы. Неактивные компоненты отмечаются отдельно.
Отчёты сохраняются в логах, telemetry и `history['sa_diagnostics']` с номером эпохи.

Checkpoint сохраняет расширенные веса, состояния Adam/scheduler, данные RAR,
историю и состояние early stopping. Старые истории получают `convergence_loss`
из сохранённых невзвешенных MSE. При восстановлении лучшей модели до последнего
RAR новые строки SA инициализируются исходным значением, размер текущей выборки
сохраняется.
