# Airfoil PINN

Проект обучает параметрическую PINN для стационарного двумерного
несжимаемого обтекания профиля. Сеть получает безразмерные координаты,
обязательный дифференцируемый SDF и настраиваемые параметры режима; выдаёт
`u/U∞`, `v/U∞` и коэффициент давления `Cp`.

Подробная инструкция по конкретному эксперименту `fvm3` с геометрией,
формулами потерь, схемой сети и командами повторного запуска:
[HTML с встроенными иллюстрациями](docs/FVM3_EXPERIMENT.html) ·
[исходник Markdown](docs/FVM3_EXPERIMENT.md).
Инструкция также описывает обнаруженные ограничения текущей постановки
интегрального баланса и восстановления прерванных checkpoint.

Каноническое описание физического и программного контракта находится в
[docs/PINN_CFD_CONTRACT.md](docs/PINN_CFD_CONTRACT.md). В нём приведены:

- нормировка по хорде, скорости набегающего потока и динамическому давлению;
- порядок входных признаков, смысл `cos(alpha)` и `sin(alpha)`;
- граф autodiff, PDE/BC/FVM/RAR/SA составляющие loss;
- требования к конфигурациям и совместимости checkpoint;
- команды приёмочных тестов и известные границы применимости.

Отдельный математический и конфигурационный контракт FVM-loss описан в
[docs/FVM_OBJECTIVE.md](docs/FVM_OBJECTIVE.md).

Быстрая проверка проекта из этой директории:

```powershell
$env:PYTHONPATH = (Get-Location).Path
Get-ChildItem tests -Filter '*.py' |
    Sort-Object Name |
    ForEach-Object { python $_.FullName }
```

Проект сначала использует существующее окружение `D:\Python\BaseEnv`,
затем локальный `venv`. Если оба отсутствуют, локальный `venv` создаётся
автоматически средствами установленного Python. Недостающие обязательные
пакеты в локальном `venv` устанавливаются через pip (нужен доступ к индексу пакетов).
Переменная `AIRFOIL_PINN_PYTHON_ENV` явно задаёт окружение и имеет высший приоритет.
Для запуска из активного окружения выполните `python Airfoil_PINN.py`;
на Windows также доступен `run.bat`. Проверки выше запускаются из активного окружения.
Общее окружение на диске D и явно заданные внешние окружения автоматически
не изменяются: при отсутствии окружения или зависимости выводится диагностика.

Основные пользовательские конфигурации находятся в `workspace/configs`.
Обучение следует запускать штатным CLI проекта; на Windows при
`data.num_workers > 0` точка входа обязана находиться под
`if __name__ == "__main__":`.
