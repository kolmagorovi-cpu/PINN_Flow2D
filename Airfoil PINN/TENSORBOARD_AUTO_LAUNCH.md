# Автоматический TensorBoard для Airfoil PINN

## ✅ Готово! TensorBoard теперь запускается автоматически

### Как это работает

При запуске обучения TensorBoard:
1. **Автоматически запускается** в фоновом режиме
2. **Не требует ручных действий** - просто начните обучение
3. **Не мешает обучению** - работает в отдельном потоке
4. **Автоматически останавливается** при завершении обучения

### Быстрый старт

Просто запустите обучение как обычно:

```bash
python Airfoil_PINN.py
```

В начале обучения вы увидите сообщение:
```
🚀 TensorBoard запускается в фоновом режиме...
✅ TensorBoard успешно запущен
📊 Откройте браузер: http://localhost:6006
```

### Настройка через конфигурацию

В файле конфигурации YAML (`Configs/your_config.yaml`) есть параметры:

```yaml
output:
  use_tensorboard: true              # Включить/выключить TensorBoard
  tensorboard_port: 6006             # Порт для веб-интерфейса
  tensorboard_auto_launch: true      # Автоматический запуск
  tensorboard_log_dir: "logs"        # Директория для логов
```

### Отключение автоматического запуска

Если хотите запускать TensorBoard вручную:

**Вариант 1: Через конфигурацию**
```yaml
output:
  tensorboard_auto_launch: false
```

**Вариант 2: Командная строка**
```bash
tensorboard --logdir=logs
```

### Что логируется в TensorBoard

Автоматически (без дополнительных настроек):

#### Потери
- `Loss/total` - полная ошибка
- `PDE/cont`, `PDE/mom_x`, `PDE/mom_y` - невязки PDE
- `PDE/laplace` - ошибка уравнения Лапласа (для потенциала)
- `BC/inlet`, `BC/outlet`, `BC/wall` - граничные условия

#### Градиенты
- `Gradients/PDE_norm` - норма градиентов PDE
- `Gradients/BC_norm` - норма градиентов BC
- `Gradients/cosine` - косинус угла между градиентами

#### Физика
- `Mass/balance_error` - ошибка баланса масс
- `Velocity/avg_u_in` - средняя скорость на входе
- `Velocity/avg_u_out` - средняя скорость на выходе

### Дополнительные методы логирования

В коде обучения можно добавить:

```python
# Логирование весов модели (раз в N эпох)
visualizer.log_model_weights(model, epoch)

# Логирование изображений полей
visualizer.log_image('Fields/velocity_u', velocity_image, epoch)

# Логирование гистограмм
visualizer.log_histogram('Distributions/residuals', residuals, epoch)
```

### Устранение проблем

#### TensorBoard не запускается

**Ошибка**: `TensorBoard не установлен`
**Решение**: 
```bash
pip install tensorboard
```

#### Порт 6006 занят

**Сообщение**: `Порт 6006 занят, ищу свободный...`
**Решение**: Система автоматически найдет свободный порт (6007, 6008, и т.д.)

#### Логи не появляются в TensorBoard

**Проверьте**:
1. `use_tensorboard: true` в конфигурации
2. Директория `logs` существует и доступна для записи
3. Обучение действительно проходит (есть вызовы `visualizer.update_plot()`)

### Полный контроль

Для полного отключения TensorBoard:

```yaml
output:
  use_tensorboard: false
```

Тогда будет использоваться только matplotlib (если `plot_frequency > 0`).

### Технические детали

- **Фоновый поток**: TensorBoard запускается в daemon-потоке
- **Не блокирует**: Основной поток обучения не ждет запуска
- **Автоматический поиск порта**: Если порт занят, выбирается следующий
- **Корректная остановка**: При завершении обучения TensorBoard останавливается
- **Cross-platform**: Работает на Windows, Linux, macOS
