## Обзор проекта

Airfoil PINN — программный комплекс на Python для моделирования обтекания профилей с помощью физически-информированных нейронных сетей (PINNs). Решает уравнения Навье-Стокса для вязкой несжимаемой жидкости.

## Модули проекта

### 1. Airfoil_PINN.py — Главный модуль управления

**Назначение:** Точка входа в приложение, главное меню и навигация по модулям.

**Функционал:**
- Запуск программы и отображение главного меню
- Навигация по 6 основным модулям
- Отображение статусов модулей (готов/разработка)

**Меню:**
1. Геометрия (G2D)
2. Дискретизация (S2DR)
3. Свойства жидкости (Fluids)
4. Граничные условия (Conditions)
5. Инициализация (Initializer)
6. Обучение PINN (PINNLearning)

---

### 2. Geometry.py (G2D) — Модуль геометрии

**Назначение:** Загрузка координат профиля и построение расчётной области.

**Классы:**
- `AirfoilGeometry` — работа с геометрией
- `GeometryConfig` — конфигурация геометрии

**Функционал:**
- Загрузка координат профиля (.npy, .csv, .txt)
- Определение замкнутости профиля
- Вычисление хорды профиля
- Создание расчётной области

**Выходные файлы:**
- `Geometry/Data/airfoil_foil.npy` — координаты профиля
- `Geometry/Data/airfoil_domain.npy` — вершины области
- `Geometry/Data/airfoil_metadata.npy` — метаданные

---

### 3. Collocation.py (S2DR) — Модуль дискретизации

**Назначение:** Генерация точек коллокации внутри области и на границах.

**Классы:**
- `CollocationPoints` — генерация и классификация точек
- `SamplerConfig` — конфигурация дискретизации
- `BoundaryType` — типы границ (inlet, outlet, wall, symmetry, axis_symmetry)

**Методы генерации:**
- `regular` — равномерная сетка
- `irregular` — случайное распределение
- `adaptive_foil` — сгущение к профилю
- `adaptive_all` — сгущение ко всем границам

**Выходные файлы:**
- `Sampler/Data/collocation_points.npy` — точки с классификацией
- `Sampler/Data/collocation_points_metadata.npy` — метаданные

---

### 4. Fluids.py — Модуль свойств жидкости

**Назначение:** Управление библиотекой жидкостей/газов.

**Классы:**
- `Fluid` — параметры жидкости (ρ, ν, μ)
- `FluidLibrary` — библиотека в JSON

**Примеры:**
- Воздух (20°C): ρ=1.204 кг/м³, ν=1.516e-5 м²/с
- Вода (20°C): ρ=998 кг/м³, ν=1.004e-6 м²/с

---

### 5. Conditions.py — Модуль граничных условий

**Назначение:** Задание граничных условий.

**Классы:**
- `BoundaryConditions` — параметры ГУ
- `ConditionsManager` — управление наборами условий

**Параметры:**
- Давление на входе/выходе [Па]
- Скорость на входе (компоненты или модуль+угол)
- Тип симметрии

---

### 6. Initializer.py — Модуль инициализации

**Назначение:** Нормализация данных и вычисление SDF.

**Функционал:**
- Нормализация: x/chord, u/U_inf, p/(ρU²), sdf/chord
- Вычисление SDF многопроцессорно (KD-дерево)
- Визуализация полей (scatter)

**Выходные файлы:**
- `Initial/Data/initial.npy` — нормализованные данные
- `Initial/Plots/*.png` — графики полей

---

### 7. PINN_Learning.py — Модуль обучения

**Назначение:** Интерактивное меню для настройки и запуска обучения.

**Меню:**
1. Создать новую конфигурацию
2. Загрузить конфигурацию
3. Редактировать конфигурацию
4. Сохранить конфигурацию
5. Показать текущую конфигурацию
6. Настройки процесса обучения
7. Старт обучения

---

### 8. solver.py — Основной решатель

**Назначение:** Координация процесса обучения PINN.

**Компоненты:**
- `LossComputer` — вычисление функции потерь
- `Trainer` — прямой проход и шаги оптимизации
- `MetricsCollector` — сбор метрик
- `InteractiveHandler` — обработка горячих клавиш
- `CheckpointManager` — сохранение/загрузка
- `KeyListener` — фоновый слушатель клавиатуры
- `Visualizer` — визуализация в реальном времени

**Функционал:**
- Двухэтапное обучение (two_stage)
- Переключение Adam → L-BFGS
- Детектор локальных минимумов
- RAR (Residual-based Adaptive Refinement)
- Градиентное накопление
- AMP (Automatic Mixed Precision)

**Горячие клавиши:**
- `Ctrl+P` — сохранить графики
- `Ctrl+W` — редактировать веса
- `Ctrl+R` — сброс оптимизатора
- `Ctrl+S` — сохранить чекпоинт
- `Ctrl+L` — увеличить LR
- `Ctrl+K` — уменьшить LR
- `Ctrl+U` — установить LR вручную

### 9. solver_components/ — Компоненты решателя

#### loss_computer.py
Вычисление PDE невязок, граничных условий, интегральных условий.

#### trainer.py
Прямой проход, шаги Adam/L-BFGS, адаптивная балансировка весов, RAR.

#### metrics.py
Сбор и логирование метрик обучения.

#### optimizers.py
- `LocalMinimaDetector` — детектор плато
- `CyclicLR` — циклический learning rate

#### interactive.py
Обработка интерактивных действий пользователя.

### 10. models.py — Модели нейронных сетей

**Классы:**
- `PINNIncompressible` — полносвязная сеть для (u, v, p)
- `SelfAdaptiveWeights` — обучаемые веса для SA-PINN
- `Sine` — синусоидальная активация (SIREN)

---

### 11. pde_residuals.py — Невязки уравнений

**Методы:**
- `compute_residuals_2d()` — для 2D плоского течения
- `compute_residuals_axisymmetric()` — для осесимметричного течения

**Уравнения:**
- Неразрывность: ∂u/∂x + ∂v/∂y = 0
- Импульс по x/y: u·∂u/∂x + v·∂u/∂y + (1/ρ)·∂p/∂x - ν·∇²u = 0

## Типичный рабочий процесс

1. **Geometry** → загрузка профиля, создание области
2. **Collocation** → генерация точек коллокации
3. **Fluids** → выбор/создание жидкости
4. **Conditions** → задание граничных условий
5. **Initializer** → нормализация, вычисление SDF
6. **PINNLearning** → настройка конфигурации
7. **Запуск обучения** → solver.py координирует процесс
8. **Результаты** → чекпоинты, графики, логи в Checkpoints/

---

## Стратегии обучения

### Двухэтапное обучение
1. **Этап 1:** Обучение с акцентом на BC
2. **Этап 2:** Постепенное увеличение веса PDE

### Переключение на L-BFGS
- После N эпох Adam → L-BFGS для точной сходимости

### RAR (Residual-based Adaptive Refinement)
- Периодическое добавление точек с максимальными невязками

### SA-PINN (Self-Adaptive)
- Обучаемые веса для каждой точки
- Автоматическая балансировка вклада точек

## Диагностика

**Визуальная:**
- Графики потерь в реальном времени
- Карты невязок
- Профили скорости в сечениях
- 2D спектр (FFT)

**Количественная:**
- Нормы градиентов PDE/BC
- Ошибка баланса масс
- Средние скорости на границах
- L2 ошибка относительно эталона
